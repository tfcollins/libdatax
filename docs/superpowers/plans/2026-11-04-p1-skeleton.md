# libdatax P1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A C11 `libdatax` with the whole v1 header, the P1 subset implemented (context, device immediate verbs, capabilities, Tick time, errors, version), a ctypes `datax` Python package with `doctor`, and a Tier 1 suite against the libiio v1 emulator that runs in GitHub CI in under five minutes.

**Architecture:** One shared library built by CMake, one header. A platform table folds IIO devices into `datax_device` objects (ad936x, adrv9009, tick, unknown). All reads and writes go through libiio v1 `iio_attr_*`. Tests launch `iiod-emu` from the pinned libiio fork on a free port per test and talk to it over `ip:127.0.0.1:<port>`. Python wraps the C ABI with ctypes and no compiled extension.

**Tech Stack:** C11, CMake ≥ 3.20, libiio v1 (fork `tfcollins/libiio` at the pin in `pins.json`, built with `-DWITH_EMU_BACKEND=ON -DWITH_IIOD_EMU=ON -DWITH_TESTS=OFF`), Python ≥ 3.11 + ctypes + pytest, GitHub Actions ubuntu-latest.

**Spec:** `docs/superpowers/specs/2026-11-04-libdatax-p1-design.md` (copy of the SDK repo's `specs/2026-11-04-libdatax-p1-design.md`). The API contract is the SDK repo's `docs/api-c-core.md`, `docs/api-object-model.md`, `docs/api-python.md`; read them from `/home/tcollins/dev/datax-sdr/datax_sdk_sdr/docs/` or <https://tfcollins.github.io/datax_sdk_sdr/>.

## Global Constraints

- Every C file starts with `// SPDX-License-Identifier: MIT`; Python files with `# SPDX-License-Identifier: MIT`.
- Compile flags: `-std=c11 -Wall -Wextra -Wshadow -Wpointer-arith -Wcast-qual -Wstrict-prototypes -Wmissing-prototypes -Werror`.
- Public symbols are exactly the `datax_*` prototypes in `api-c-core.md` plus `datax_internal_tick_descriptor_pack` (test-only). `src/libdatax.map` lists them; everything else is local.
- Every function returns 0 or `-errno`; every `-errno` return sets the context's last error (`error.c`). Unimplemented-in-P1 symbols return `-ENOTSUP` with the message `"<verb>: arrives in P<n>"`.
- No global mutable state. Context and device calls lock a per-context mutex.
- Pins: `pins.json` carries `libiio` = `6534f14215f4738cec224bf50f13f475fe5264a6` (branch `feature/daqiri-udp`), `tick` = `ed6c8a4c955d1933eb5da33f3c1fefcb72d32123` (`main`), `pyadi_iio` = `8ccb1de4a00698887bd50cb8a3945262ccb2f97f` (fixture source only). Bumps are deliberate commits with a `why`.
- libiio v1 calls to use: `iio_create_context(NULL, uri)`, `iio_context_destroy`, `iio_context_get_devices_count`, `iio_context_get_device`, `iio_context_find_device`, `iio_device_get_name`, `iio_device_get_id`, `iio_device_find_attr`, `iio_device_find_channel(dev, name, output)`, `iio_channel_find_attr`, `iio_attr_read_longlong/double/raw`, `iio_attr_write_longlong/double/raw`, `iio_context_get_version_major`. Check their exact signatures in `include/iio/iio.h` of the pinned fork; they return `int` or pointers with `iio_err()` for error pointers.
- Emulator: `iiod-emu <xml> -p <port>` from the libiio build (`build/iiod-emu/iiod-emu`); the environment variable `DATAX_LIBIIO_BUILD` points at that build directory in tests and CI. Tests must pick a free port (bind 0, close, reuse) and wait for the port to accept before connecting; never a fixed port.
- `git commit -s`. Each task is one PR-sized change on its own worktree branch `task/<n>-<slug>`; merge to `main` after its tests pass.
- Never put lab host names or IPs in the repo.

## Review Focus

1. A context with no known device (e.g. the Tick XML alone) must create successfully with device count 0 and all caps false, not fail — Task 6 `test_caps_bare_context`.
2. Destroying a context must destroy its devices and leave no libiio handle leaked (valgrind-clean on `test_context`) — Task 3 runs `test_context` under valgrind when available.
3. A timed verb (`when != DATAX_TIME_NOW`) must return `-ENOTSUP`, set last-error, and leave the attribute unchanged — Task 4 `test_timed_set_is_enotsup_and_no_write`.
4. Python must never segfault on a bad handle after `with` exit: every wrapper checks a closed flag and raises `datax.Error` — Task 8 `test_use_after_close_raises`.
5. The CI job must fail if it exceeds five minutes, not merely be slow — Task 9 `timeout-minutes: 5` on the test job.
